# Security and payment handling.

> Security and payment handling information for Logicleap Technologies websites, apps, and services.

- Canonical HTML: https://logicleaptechnologies.com/security.html
- Markdown: https://logicleaptechnologies.com/security.md

Logicleap uses practical safeguards to protect websites, software services, support communications, and payment workflows.

## Website security

This website is intended to be served over HTTPS. Do not submit sensitive information over an insecure connection.

## Payment information

If online card payments are enabled for a Logicleap product or invoice, card details are handled by the payment processor. Logicleap does not store full card numbers on this website.

## Service data

Client project files, source code, and access credentials should be shared through agreed secure channels. Avoid sending secrets or passwords by plain email unless specifically instructed to use an approved secure method.

## Report a security issue

Report security concerns to [support@logicleaptechnologies.com](mailto:support@logicleaptechnologies.com). Please include a clear description, affected URL or product, reproduction steps, and your contact details.
